# Manuscript

This folder contains the submission manuscript package.

- `main.tex` - LaTeX source.
- `references.bib` - bibliography database.
- `main.bbl` - BibTeX-generated bibliography file.
- `main.pdf` - compiled PDF.
- `images/` - figures included by `main.tex`.
- `generated_outputs/` - mirrored generated outputs for traceability.
- `elsarticle-harv.bst` - bibliography style used by the manuscript.
- `elsarticle-num.bst` and `elsarticle-num-names.bst` - additional Elsevier bibliography styles kept for compatibility.
