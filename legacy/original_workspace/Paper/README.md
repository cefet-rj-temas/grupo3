# Paper

Este diretório contém a saída compilada do artigo.

## Conteúdo

- `main.pdf`: Versão compilada mais recente do artigo.

## Fontes LaTeX

Os arquivos fontes para edição do artigo estão localizados em `references/source_files/` por questões de organização histórica:

- `Paper_main.tex`: Arquivo principal.
- `Paper_Game_theoretic_Model.tex`: Definição do modelo matemático.
- `Paper_references.bib`: Base de referências bibliográficas.

## Gerados

As figuras e tabelas geradas automaticamente pelos scripts estão localizadas em `Paper/generated` (se existirem localmente).
