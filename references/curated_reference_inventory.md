# Curated Reference Inventory

This file summarizes the reference groups considered relevant to the article. The full historical PDF vault is preserved under `legacy/original_workspace/`; the active manuscript cites the bibliographic records in `manuscript/references.bib`.

## Core Source Groups

- Surfing-resource impact guidance: sources on environmental impact assessment for surfing resources, wave quality, and coastal process changes.
- Offshore wind and tourism: sources on tourist behavior, recreation demand, public acceptance, visual amenity, and coastal recreation trade-offs.
- Offshore wind and coastal processes: sources on wave damping, shoreline development, cumulative impacts, and environmental assessment for offshore energy.
- Peniche surf economy: sources on Peniche surf tourism, WSL events, local economic effects, and municipal indicators.
- Portuguese offshore policy: sources on Portugal's offshore wind planning, maritime spatial allocation, and renewable-energy targets.
- Game theory and litigation: sources on normal-form games, Nash equilibrium, litigation under uncertainty, and strategic behavior in coastal-use conflicts.
- Compensation and governance: sources on compensatory measures, sector representation, conflict management, and governance of place-based coastal assets.

## Active Bibliographic Control

The authoritative citation list for the article is `manuscript/references.bib`. This inventory is only a navigation aid for the supporting literature.
